# Change Log

## 2.0.0

- New language server, compiled to native code for (.NET runtime is no longer required)
- Project model: scripts are checked in the context of the `.bus`, `.ovh`, `.sco` and `.hum` files that load them (including varlists, string varlists and constfiles)
- New diagnostics and configurable severities
- Documentation for all keywords, operators, system macros, system triggers, system variables and predefined variables
- Completion, go to definition, find references, rename, document highlights, outline, workspace symbols, folding, quick fixes and inlay hints
- Rewritten syntax highlighting

## 1.1.1

- Files are opened with Windows 1252 encoding by default
- Hovering information added
- Several bugs have been fixed

## 1.0.1

- Initial release
